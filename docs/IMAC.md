# 在 iMac 上运行

## 你最终得到什么

家里的 iMac 是运行主机，GitHub 保存程序。控制台只在 iMac 本机的浏览器里打开（`http://127.0.0.1:8765`），不提供远程网页。iMac 断网、睡眠或断电都会中断运行。你不需要先购买云服务器。

## 第一次安装

1. 在 iMac 上下载或克隆本仓库。
2. 按 [uv 官方说明](https://docs.astral.sh/uv/getting-started/installation/)安装 uv。
3. 双击项目里的「启动模拟控制台.command」。首次启动会下载依赖。
4. 双击「打开控制台.command」，查看本机生成的访问码，登录网页。
5. 在 OKX 模拟交易区域创建专用模拟 API，将三项凭证填进网页的连接面板。不要发到聊天。
6. 检查账户、运行历史检验，设定资金和亏损线，再由你启动模拟试验。
7. 想试 LLM 策略：在 OpenRouter 为本程序单独创建一个 Key 并设置额度上限。在网页「策略」里选「LLM 决策」，点「设置 OpenRouter 密钥」填入，再从 openrouter.ai/models 复制模型 ID 填进去，启动模拟试验。

Mac 若拦截打开脚本，需要你自行检查并处理系统提示；不要关闭系统安全机制。也可在终端进入项目目录，运行 README 中的命令。

若你自行决定启用实盘，改用「启动实盘控制台.command」，或在启动命令末尾加 `--allow-live`。原有策略不会随服务启动自动恢复，仍需你在网页启动。

## OKX API 与家庭网络 IP

OKX 创建 API 时可以绑定 IP 白名单。家庭宽带的公网 IP 经常变化，绑定后一旦 IP 变了，请求会被 OKX 拒绝，程序会暂停策略，不会继续下单。不绑定 IP 可以避免这个问题，但 OKX 对未绑定 IP、带交易权限的 API 有额外限制（例如长期不用会失效），以创建 API 时页面上的说明为准。无论哪种方式，都不要给 API 提现权限。

## 登录后后台运行（可选）

前台窗口够用时可以跳过这一节。先关闭之前的前台控制台，避免两个进程占同一端口。在项目目录由你运行：

```sh
uv run python scripts/service.py install
```

需要允许自己使用实盘功能时，在上面的安装命令末尾加 `--allow-live`。安装器只启用服务能力，不启动交易试验。

后台服务通过 macOS LaunchAgent 在登录后启动，进程运行期间用 `caffeinate -i` 防止自动空闲睡眠。异常退出会重启服务，但策略自动暂停，需要你确认后重新启动。

移除后台服务：

```sh
uv run python scripts/service.py uninstall
```

这不删除本机账户数据，也不取消已经提交给 OKX 的订单。

## 电源、重启与登录

- 屏幕关闭可以；不要让系统自动睡眠。Apple 设置在不同 macOS 版本的「节能」或「锁定屏幕」中，参考 [Apple 睡眠说明](https://support.apple.com/en-om/guide/mac-help/-mchlp2995/mac)。
- 手动睡眠、断电、拔网线仍会中断。电脑不是交易所端的托管止损服务。
- LaunchAgent 需要用户已经登录。完全注销会终止它；FileVault 重启后等待解锁时也不能保证自动恢复。不要为此关闭磁盘加密。
- 服务运行期限和策略运行期限不同：主机可以常开，策略仍按你设定的 1–24 小时到期。到期不自动清仓。

## 凭证与数据

所有账户密钥、访问码、本机解密密钥、SQLite 账本都在项目 `data/` 中，不会提交 GitHub。不要把此目录放进公开网盘或发送给别人；备份时加密并同时保存密文和解密密钥。迁移主机前先停止策略并核对未决订单，避免同一试验在两台机器同时运行。
