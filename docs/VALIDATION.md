## 2026-09-27 LLM 决策策略

- 新增 `lab/llm.py` 与 LLM 策略：每根新收盘小时 K 线最多询问一次 OpenRouter 模型，回答只能是买入／卖出／持有。模型在引擎锁外调用，回答写入账本后由新一轮检查执行，因此到期、暂停、未决订单、亏损线、每日次数、仓位上限在下单前都会重新检查。
- OpenRouter Key 经 `GET /api/v1/key` 验证后与交易所凭证一样加密存放在 `data/`，接口与日志不回显。
- `uv run python -m pytest -q`：49 项通过（新增 17 项，全部使用模拟对象或 MockTransport）；`node --check static/app.js`：通过。
- 本机 Chromium 检查 1440px 与 390px：选择 LLM 后才显示模型字段，页面无横向溢出，历史检验按钮给出不可回测提示，密钥对话框可打开，无脚本错误。

### 尚未验证

## 2026-09-27 修复

- 策略检查只取一页 100 根小时 K 线，而 OKX 最新一页包含正在形成的那根，已收盘只有 99 根，首次检查即暂停。改为取两页。新增测试用 MockTransport 按真实分页格式返回数据，经真实 `OkxClient` 走完启动、检查、下单；修复前该测试失败。
- 买入手续费按币扣，全部卖出后账本留下低于最小下单量的零碎币，试验无法归档；触及亏损线的试验因此既不能续期也不能结束。现在低于最小下单量的零碎币可以归档，数量与估值写入归档和事件。
- OKX 单笔拒单返回顶层 code 1、原因在 sCode；此前只报告 1。现在报告 sCode，并写入冻结提示。拒单后的处理不变：仍冻结、不重发。
- 移除 Tailscale 远程访问与 `--origin` 参数，服务只供本机浏览器使用。删除未使用的旧策略框架代码（`lab/base.py` 与 `rsi.py` 中的旧 evaluate）。
- `uv run python -m pytest -q`：32 项通过；`node --check static/app.js`：通过。仍未使用任何真实或模拟账户凭证。
